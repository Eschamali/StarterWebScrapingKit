> [!NOTE]
> Demoコードは、下記のテストをしています
> * ShadowDOM内にあるボタンをクリックした瞬間、ボタンがエメラルドグリーンに光る✨  
> * ShadowDOM深部にあるテキストボックスに文字が入力された瞬間、背景色が変わり目立つようになる✨  
> * DEEP要素のテキスト検索が成功すると、「テキスト書き換えにも成功しました！」という文字に置き換わり青く光る✨  
> * 最後の「全テキストボックス探索」では、取得された（見つかった）すべての要素が順番に黄色くフラッシュする✨  
> * ブラウザがすぐに閉じてしまって見えないのを防ぐため、最後の待機時間を br.sleep 8 (8秒) に延長
