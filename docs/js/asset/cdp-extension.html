CDPの機能拡張（テンプレート利用）

コアクラスを汚さずに機能を拡張する

本ツールはメンテナンス性を維持するため、ベースとなる CDPBrowser.cls などのコアファイルには「あえて便利なラッパーメソッドを追加しない」という設計思想を持っています。
しかし、特定のプロジェクトにおいて「非同期イベントを継続的に監視したい」「定型的な複数コマンドをまとめたい」といった高度な要求が発生することがあります。

こうした場合に備え、コア（VBAProject\Class）を変更せずに自由に独自の拡張を行えるよう、専用の拡張テンプレートクラスが用意されています。

💡
テンプレートの場所

ForDevelopers\TemplateExtensions\CDP\Template_CDPexpansion.cls

機能拡張の仕組み

拡張クラスでは、VBAの WithEvents を用いてベースとなる CDPBrowser と連携します。
これにより、ブラウザ側から送られてくるあらゆる非同期イベント（ネットワーク通信の完了や画面の描画など）をリアルタイムに横取り（フック）して、あなたの好きな処理を自動実行させることができます。

開発のステップ

  1. Template_CDPexpansion.cls をコピーし、好きな名前に変更してプロジェクトに取り込みます。
  2. メインの処理内で、拡張クラスを New して Init メソッドに CDPBrowser インスタンスを渡して継承させます。
  3. 拡張クラス内の ex_CDPBrowser_detectionCDPEvent メソッドに、横取りしたい非同期イベント名（例：Network.responseReceived）と処理内容を記述します。

【デモ】JavaScriptダイアログの自動クローズ機能

拡張機能の強力な例として、「JavaScriptアラートを自動で閉じる」デモが用意されています。

🚀
デモの場所

Extensions\CDP\JavaScript alert - Automatically close

本デモの CDPexpansion_JSDialogAutoClose.cls では、以下の制御を実現しています。

  • 非同期での処理: Page.javascriptDialogOpening イベントを常時監視します。
  • 自動処置: ダイアログが開いたことを検知すると、即座に Page.handleJavaScriptDialog を発行し、「OK」や「キャンセル」の送信、さらにはプロンプトへのテキスト自動入力まで行います。
  • UIを止めない: 通常、アラートが表示されるとブラウザの処理がブロックされますが、この拡張機能を使えば裏側で自動的に応答するため、VBAのメインループに一切影響を与えません。 
' デモ的使用例
Dim Demo_alerts As CDPContext
Set Demo_alerts = 設定シートからのCDP起動forTab("https://www.selenium.dev/selenium/web/alerts.html")

' 拡張機能のセットアップ
Dim testEX As New CDPexpansion_JSDialogAutoClose
testEX.Init Demo_alerts.InheritanceCDPBrowser

' デフォルトでOKを選択し、テキストを入力する設定
testEX.DefaultAccept = True
testEX.DefaultPromptText = "VBAから自動入力！"

' あとは普通に操作するだけ。Alertは裏で自動処理される
Demo_alerts.ExecuteCDP "DOM.enable"
' ... クリックなどの処理が続く

このように、「低レベルな ExecuteCDP のベース」と「AIが生成するコード」、そして「拡張テンプレートによる非同期制御」を組み合わせることで、どんなに複雑なブラウザ操作要求にも応えることができる最強の土台が完成します。
