メソッド リファレンス：WebDriverBiDiContext

WebDriverBiDiContext.cls が公開する Public メソッド・Propertyの完全リファレンスです。
BiDi セッション上の1コンテキスト（タブ相当）を操作します。多くのデモは 設定シートからのBiDi起動ForTab でこのクラスのインスタンスを取得します。
各項目をクリックすると、シグネチャ・引数・使い方が展開されます。

💡
BiDiCDPJson の読み方

ExecuteBiDi の戻り値は BiDiCDPJson です。

Dim resultBiDi As BiDiCDPJson
Set resultBiDi = ctx.ExecuteBiDi("goog:cdp.getSession")
If Not resultBiDi Is Nothing Then Debug.Print resultBiDi.StringKey("session")
🌉
ConvertToCDPContext — BiDi と CDP の橋渡し

BiDi だけでは要素操作（click, sendString 等）ができません。詳細な DOM 操作が必要な場合は ConvertToCDPContext() で CDPContext に変換して CDP スタックの API を利用してください。

🌉 CDP への変換

ConvertToCDPContext Function → CDPContext現在の BiDi コンテキストに対応する CDPContext を生成する 
Public Function ConvertToCDPContext() As CDPContext

同一ブラウザ・同一タブ上で CDP の要素操作 API を使えるようになります。変換失敗時は Nothing が返ります。

Dim cdpCtx As CDPContext
Set cdpCtx = bidiCtx.ConvertToCDPContext()
cdpCtx.getElementByID("submit").click
