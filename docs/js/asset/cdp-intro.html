当プロジェクト独自の特徴と設計思想

このツールは、偉大なオリジナル「Chromium-Automation-with-CDP-for-VBA」への最大限の敬意から生まれました。
しかし、我々は、 日本の、VBAの"現場" で日々戦うあなたのために、歩みを止めるわけにはいきませんでした。

🌟 Excelこそが、あなたの司令塔

もうVBAのコードとにらめっこする必要はありません。あなたの戦場は、使い慣れた「Excelシート」の上にもあります。

  • 脱・ハードコーディング: 起動設定はすべて「ブラウザ起動設定」シートに書き込むだけ。コードを一切変更せずに設定を切り替えられます。
  • ポータブルブラウザ完全対応: PCに直でインストールされたブラウザだけでなく、USBメモリの中にあるポータブル版ブラウザも指定可能です。
  • さらば、tmpフォルダ: セッション情報などのデバッグの痕跡は、散らかることなくワークシート上の「テーブル」に美しく記録されます。

🧠 設計思想：なぜ「Excel」に特化したのか？

本ツールは汎用的な「Office全般で動くコード」ではなく、あえて 「Excel専用」 の進化を遂げました。
なぜなら、Excelが持つ以下の「神の力」をフル活用するためです。

  • 究極のGUIであり、データベースである 「セル」
  • 頼れる賢者の知恵 「WorksheetFunction」
  • 世界の理をねじ曲げる禁断の魔法 「Evaluate」

中途半端な汎用性を捨て、Excel VBAのポテンシャルを120%解き放つことを選んだ異端児――それがこのスターターキットです。

⚔️ 脱・WebDriver：バージョン追っかけごっこの終焉

Seleniumなどの従来の手法では、ブラウザの自動更新という「審判」が下るたび、一致する webdriver.exe を探し出し、パスを通すという苦行が必要でした。
当プロジェクトは、ブラウザと「直接対話」するCDP方式を採用しているため、そんな煩わしさという呪縛からあなたを解き放ちます。

🛡️
ドライバレスの真価

外部実行ファイルに頼ることなく、OSの標準機能（パイプ）のみでブラウザを支配します。それはつまり、IT制限の厳しい環境でも、ブラウザさえあればそこがあなたの自動化の聖域になることを意味します。

  • Version Free: ブラウザが勝手にアップデートされても、もう慌ててドライバを探す必要はありません。
  • Zero Setup: 特殊なドライバの配布や環境変数への登録は一切不要。ブックを共有するだけで、即座に自動化が始まります。
  • Ultra Response: HTTP プロトコルを介さない直結の「パイプ通信」が、Seleniumでは到達できない極限のレスポンスを提供します。
