メソッド リファレンス：CDPElement

CDPElement.cls が公開する Public メソッド・Propertyの完全リファレンスです。
objectId ベースで DOM 要素を操作するラッパーです。通常は CDPContext.getElementBy* から取得します。
各項目をクリックすると、シグネチャ・引数・使い方が展開されます。

🔧 初期化

Init Sub内部生成用の初期化（通常は直接呼ばない） 
Public Sub Init(InheritanceCDPContext As CDPContext, argResultVarType As VbVarType, objectid_ As String, Optional JavaScriptStr As String)

CDPContext.getElementBy* 内部で使用されます。

ExposeDevTools SubDevTools コンソールに要素を変数として公開する 
Public Sub ExposeDevTools(varName As String)

コンソールで varName として要素を参照できるようになります。

🖱️ 操作

click Function → Boolean要素をクリックする 
Public Function click(Optional till As ReadyState = isComplete) As Boolean

till でクリック後の ReadyState 待機が可能です。

submit Function → Booleanフォームを送信する 
Public Function submit(Optional till As ReadyState = isComplete) As Boolean
focus Function要素にフォーカスを当てる 
Public Function focus()
fireEvent Function → Boolean任意の DOM イベントを発火する 
Public Function fireEvent(strEventName As String, Optional till As ReadyState = isComplete) As Boolean

例: "change", "input", "mouseover"

sendString Function → Booleanテキストを入力する（日本語・絵文字対応） 
Public Function sendString(textToSend As String) As Boolean

CDP Input.insertText ベースで、IME 不要の直接入力です。

sendClick Function → Boolean要素の座標をクリックする 
Public Function sendClick() As Boolean

要素の中心座標に対してマウスクリックを送信します。

sendKey Function → Booleanキーボード入力を送信する 
Public Function sendKey(Key As keyboardCode, Optional altKey As Boolean = False) As Boolean

keyboardCode Enum でキーを指定します。altKey:=True で Alt 修飾。

clearValue Function → Boolean入力フィールドの値をクリアする 
Public Function clearValue() As Boolean
selectText Function要素内のテキストを全選択する 
Public Function selectText()
setSelection Functionselect 要素の option を選択する 
Public Function setSelection(strOptionName As String)

option の表示テキストまたは value で選択します。

⏳ 存在確認・待機

isExist Function → Boolean要素が DOM 上に存在するか即時確認する 
Public Function isExist() As Boolean
onExist Function → CDPElement要素の出現までポーリングし、見つかった CDPElement を返す 
Public Function onExist(Optional timeOutInSeconds As Double = 30, Optional raiseTimeoutError As Boolean = True) As CDPElement
引数説明
timeOutInSecondsタイムアウト秒数（デフォルト 30）
raiseTimeoutErrorタイムアウト時に例外を発生（デフォルト True）
onExistNot Function → Boolean要素の消失までポーリングする 
Public Function onExistNot(Optional timeOutInSeconds As Double = 30) As Boolean

要素が消えるまで待機し、成功時 True を返します。
