mapperTab.js の更新方法

BiDi制御の心臓部である mapperTab.js は、Chromium のアップデートに合わせて定期的に更新することが推奨されます。
更新方法は以下の2パターンです。ソースは Demo_WebDriverBiDi.bas の「アップデート Demo」にあります。

📊 2つの更新パターン比較

🌐 NPM / jsDelivr 経由（オンライン）📁 ローカルファイル経由（オフライン）
通信インターネット接続が必要不要（企業内制限環境向け）
バージョン自動で最新版を取得手元の .js ファイルを使用
バージョン記録ワークシートに自動記録" Local" としてワークシートに記録
手間実行するだけ（最も簡単）事前に .js ファイルを用意する必要あり

🌐 パターン1：NPM / jsDelivr 経由（推奨）

jsDelivr CDN から chromium-bidi の最新 mapperTab.js を自動でダウンロードし、Excelのワークシートへ書き込みます。
現在のバージョン ＝ NPM最新版 の場合は更新をスキップして教えてくれます。

✅
使い方

VBEで Demo_WebDriverBiDi.bas を開き、npm経由で更新 プロシージャを実行するだけです。

コードを見る（npm経由で更新） 
Private Sub npm経由で更新()
    Dim UpdateBiDi As New WebDriverBiDiCore
    With ShLibrary01_JS
        '1. 現在のバージョン確認
        Dim mapperTab_npmVersion        As String: mapperTab_npmVersion = UpdateBiDi.UpdateCheckNPMVersion
        Dim mapperTab_WorkSheetVersion  As Range: Set mapperTab_WorkSheetVersion = .Range(.UseRangeName(1, "Demo_WebDriverBiDi.npm経由で更新"))
        If mapperTab_npmVersion = mapperTab_WorkSheetVersion.value Then MsgBox "すでに`mapperTab.js`は、最新バージョンです。", vbExclamation, "既に最新です(" & mapperTab_WorkSheetVersion & ")": Exit Sub

        '2. npmで更新
        Dim UpdateSuccess As Boolean: UpdateSuccess = UpdateBiDi.UpdateFromNPMFile
        If UpdateSuccess Then MsgBox "npm経由で、アップデートに成功しました。", vbInformation, "Success(" & mapperTab_WorkSheetVersion & " → " & mapperTab_npmVersion & ")" Else MsgBox "npm経由での、アップデートに失敗しました。Excelに埋め込んだJavaScript文字列とnpm経由での一致が確認できませんでした。", vbCritical, "failure"

        '3. バージョンをワークシートに記録
        '※ミスの場合は、空欄にする
        mapperTab_WorkSheetVersion.value = IIf(UpdateSuccess, mapperTab_npmVersion, "")
    End With
End Sub

処理フロー

① バージョン確認 → UpdateCheckNPMVersion が jsDelivr API を叩いて最新バージョン文字列を取得
↓ ワークシートの記録値と比較
② 差異があれば更新 → UpdateFromNPMFile が mapperTab.js 本体をダウンロードしてセルへ分割格納
↓
③ バージョンを記録 → ワークシートのバージョンセルに新バージョン番号を書き込んで完了

📁 パターン2：ローカルファイル経由（オフライン対応）

企業のプロキシやファイアウォールでインターネットアクセスが制限されている環境向けです。
事前に別端末などで mapperTab.js を入手しておき、ダイアログで指定します。

⚠️
事前準備：mapperTab.js の入手方法

以下のどちらかの方法でファイルを入手してください。

  • jsDelivr CDN からダウンロード（推奨）
    https://cdn.jsdelivr.net/npm/chromium-bidi/lib/iife/mapperTab.js
  • NPMでビルドする場合
    npm install chromium-bidi → node_modules/chromium-bidi/lib/iife/ 内の mapperTab.js
✅
使い方

VBEで Demo_WebDriverBiDi.bas を開き、ローカルファイルで更新 プロシージャを実行。ファイル選択ダイアログが開くので、用意した .js ファイルを選択してください。

コードを見る（ローカルファイルで更新） 
Private Sub ローカルファイルで更新()
    '1. ファイルパスを、ダイアログで指定
    Dim UpdateFilePath As String
    UpdateFilePath = Application.GetOpenFilename("mapperTab File, *.js", , "WebDriverBiDiのやりとりの基となる`mapperTab.js`相当を選択してください")
    If UpdateFilePath = CStr(False) Then Exit Sub

    '2. 一旦、パスごとに分割
    Dim tmp: tmp = Split(UpdateFilePath, "\")
    Dim SplitNum As Long: SplitNum = UBound(tmp)

    '3. 分けて格納
    Dim FolderName As String, FileName As String
    FileName = tmp(SplitNum): tmp(SplitNum) = ""
    FolderName = Join(tmp, "\")

    '4. 更新処理
    Dim UpdateBiDi As New WebDriverBiDiCore
    If UpdateBiDi.UpdateFromLocalFile(FolderName, FileName) Then MsgBox "アップデートに成功しました。" & vbCrLf & UpdateFilePath, vbInformation, "Success" Else MsgBox "アップデートに失敗しました。Excelテーブルに埋め込んだJavaScript文字列とアップロードファイルとの一致が確認できませんでした。" & vbCrLf & UpdateFilePath, vbCritical, "failure"
End Sub

🔍 更新が反映されたか確認するには

更新処理が正常に完了すると、「JSライブラリ管理」シート のバージョンセルが以下のように変化します。

更新パターンバージョンセルの値
🌐 NPM経由バージョン番号（例: 0.9.0）
📁 ローカルファイル経由 Local
💡
なぜセルへ書き込むのか？

mapperTab.js は数万行のテキストファイルです。Excelのセルに分割して格納することで、「バイナリファイルを一切使わずに」 ブラウザへ注入できます。
