メソッド リファレンス：CDPBrowser

CDPBrowser.cls が公開する Public メソッド・Propertyのリファレンスです。
各項目をクリックすると、シグネチャ・引数・使い方が展開されます。タブ操作は CDPContext、要素操作は CDPElement を参照してください。

💡
BiDiCDPJson の読み方

ExecuteCDP の戻り値は BiDiCDPJson です。成功時は result ノードが返ります。エラー時（StopCDPError:=False）は Nothing → .LastCDPJsonError を参照。

⚡ CDP コマンド

ExecuteCDP Function → BiDiCDPJsonCDPコマンドを同期送信し、結果が返るまで待機する 
Public Function ExecuteCDP( _
    methodName As String, _
    Optional params As Scripting.Dictionary, _
    Optional StopCDPError As Boolean = True _
) As BiDiCDPJson
引数型説明
methodNameStringCDPメソッド名（例: "Browser.getVersion"）
paramsDictionaryパラメータ Dictionary
StopCDPErrorBoolean失敗時 Err.Raise（デフォルト True）

戻り値：成功時は CDP result ノード（BiDiCDPJson）。StopCDPError:=False で失敗時は Nothing。

ExecuteCDPAsync Function → LongCDPコマンドを非同期送信し、コマンドIDを返す 
Public Function ExecuteCDPAsync( _
    methodName As String, _
    Optional params As Scripting.Dictionary, _
    Optional StopPipeError As Boolean = True _
) As Long

戻り値のコマンドIDを TakeResultCDP に渡して結果 JSON 文字列を取得します。事前に TakeEvents が必要です。

LastCDPJsonError Property Get → Dictionary直前の同期 ExecuteCDP 失敗時のエラー情報

キー例: "code", "message"。成功後も値はリセットされないため、失敗時のみ参照してください。

TakeEvents Sub受信バッファを処理し、非同期結果・イベントを回収する 
Public Sub TakeEvents(Optional StopPipeError As Boolean = True, Optional destruction As Boolean = False)
引数説明
StopPipeErrorパイプエラー時に例外を発生（デフォルト True）
destructionTrue で JSON 解析せずバッファを高速クリア

タブ側からは CDPContext.InheritanceCDPBrowser.TakeEvents 経由で呼ぶのが一般的です。

TakeResultCDP Property Get → String非同期コマンドIDに対応する結果 JSON を取得する 
Property Get TakeResultCDP(commandID As Long) As String

取り出し後はバッファから削除されます。未着の場合は空文字列です。

SetLimitCDPResult Property Let非同期結果バッファの最大保持件数を設定する 
Property Let SetLimitCDPResult(Number As Long)

デフォルトは 10。上限超過時は古いエントリから削除されます。

TimeOutSecond Property Get/Let → Double同期 CDP コマンドのタイムアウト秒数

Get/Let で読み書き。デフォルトは 30 秒前後（実装依存）。
