メソッド リファレンス：CDPBrowser

CDPBrowser.cls が公開する Public メソッド・Propertyのリファレンスです。
ブラウザ単位（--user-data-dir 相当）の制御を担います。タブ操作は CDPContext、要素操作は CDPElement を参照してください。

💡
BiDiCDPJson の読み方

ExecuteCDP の戻り値は BiDiCDPJson です（旧 Scripting.Dictionary ではありません）。成功時は result ノードが返ります。

Dim resultCDP As BiDiCDPJson
Set resultCDP = browser.ExecuteCDP("Browser.getVersion")
If Not resultCDP Is Nothing Then
    Debug.Print resultCDP.StringKey("userAgent")
End If
' エラー時（StopCDPError:=False）: Nothing → .LastCDPJsonError

🚀 ライフサイクル

1. start ― ブラウザの起動

CDPパイプ通信を初期化し、Chromium 系ブラウザを起動します。

Public Sub start( _
    Optional Name As String = "chrome", _
    Optional appUrl As String, _
    Optional userProfile As String, _
    Optional addArgs As String, _
    Optional KioskMode As edgeKioskType)
引数型説明
NameString"chrome" または "edge"
appUrlString起動時URL（省略時 about:blank）
userProfileStringUserDataDir プロファイル名
addArgsString追加起動引数
KioskModeedgeKioskTypeキオスクモード

2. reattach / quit

reattach(userProfile) は既存セッションへの再接続（Boolean 返却）。quit はブラウザ終了とリソース解放です。

3. newTab / getTab

タブの生成・取得。戻り値は CDPContext です。getTab は tabName, Url, SearchTypeID, doRetrySecond 等を指定できます。

4. isLiveBrowser / tabCount / printTabs

ブラウザ生存確認、タブ数取得、タブ一覧のログ出力です。

⚡ CDP コマンド

5. ExecuteCDP ― 同期的な CDP 要求

CDPコマンドを送信し、ブラウザからの返事が返るまで待機します。

Public Function ExecuteCDP( _
    methodName As String, _
    Optional params As Scripting.Dictionary, _
    Optional StopCDPError As Boolean = True _
) As BiDiCDPJson
引数型説明
methodNameStringCDPメソッド名（例: "Browser.getVersion"）
paramsDictionaryパラメータ Dictionary
StopCDPErrorBoolean失敗時 Err.Raise（デフォルト True）

6. ExecuteCDPAsync ― 非同期 CDP 要求

Public Function ExecuteCDPAsync( _
    methodName As String, _
    Optional params As Scripting.Dictionary, _
    Optional StopPipeError As Boolean = True _
) As Long

戻り値はコマンドID。TakeResultCDP で後から結果JSON文字列を取得します。

7. LastCDPJsonError

直前の同期 ExecuteCDP 失敗時のエラー情報（Dictionary）。

8. TakeEvents

受信バッファを処理します。通常 CDPContext.InheritanceCDPBrowser.TakeEvents 経由で呼び出します。

Public Sub TakeEvents(Optional StopPipeError As Boolean = True, Optional destruction As Boolean = False)

9. SetLimitCDPResult / TakeResultCDP

非同期結果バッファの上限設定と、コマンドIDによる結果取得（String 返却）です。

10. TimeOutSecond

同期コマンドのタイムアウト秒数（Double、Get/Let）。
