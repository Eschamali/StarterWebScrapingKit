独自の、追加メソッド

真の力は、主に8つの根源的なメソッド・プロパティに集約されています。これらをマスターした時、あなたはブラウザという「宇宙」の時間と空間を自在に支配するでしょう。

1. ExecuteCDP ― 同期的な、"神託"の要求

「答えが、"今"欲しい」あなたのための強力な呪文。
CDPコマンドを送信し、ブラウザからの「返事」が返ってくるまで"待機"します。

Public Function ExecuteCDP( _
    methodName As String, _
    Optional params As Scripting.Dictionary, _
    Optional StopCDPError As Boolean = True _
) As Scripting.Dictionary
引数型説明
methodNameString【必須】 実行したいCDPメソッド名。（例： "Browser.getVersion"）
paramsDictionary【任意】 メソッドに渡すパラメータを格納したDictionary。
StopCDPErrorBoolean【任意】 デフォルトは True。失敗時に Err.Raise で停止します。

2. ExecuteCDPAsync ― 非同期の、"未来"への問いかけ

コマンドの応答を待たずに、即座に次の処理へ進みます。引数は ExecuteCDP とほぼ共通です。

Public Function ExecuteCDPAsync( _
    methodName As String, _
    Optional params As Scripting.Dictionary, _
    Optional StopError As Boolean = True _
) As Long

3. LastCDPJsonError ― "最後の悲劇"を記録する「石板」

ExecuteCDP が Nothing を返した原因がここに記録されています。同期実行が最後に失敗したときのエラー情報(JSONを展開したDictionary)を取得します。

4. TakeEvents ― "時"の川から、"出来事"をすくい上げる

受信バッファに溜まったすべてのメッセージを、BrowserEvents プロパティに蓄積します。通常、CDPContext.InheritanceCDPBrowser.TakeEvents を通じて呼び出します。

Public Sub TakeEvents(Optional StopPipeError As Boolean = True, Optional destruction As Boolean = False)
引数型説明
StopPipeErrorBoolean【任意】 デフォルトは True。パイプ読み取りエラー時に例外を発生させます。
destructionBoolean【任意】 Trueにすると、JSON解析を行わず、バッファを高速に空にします。

5. SetLimitCDPResult ― "未来"からの返事を受け取る「箱」の制限

非同期メソッドの結果を蓄積する内部バッファの最大件数を設定します。

Property Let SetLimitCDPResult(Number As Long)

6. TakeResultCDP ― "整理券番号"で奇跡を手に入れる

非同期で実行したコマンドの整理券番号 (CommandID) を指定して、後からその結果を取り出します。

Property Get TakeResultCDP(commandID As Long) As String
引数型説明
commandIDLong【必須】 ExecuteCDPAsync が返した整理券番号。

7. TimeOutSecond ― "待つ"ことの限界を定義する

同期的なコマンドがブラウザからの応答を何秒間待つかを設定/取得します。データ型が実数（Double）になりました。

Property Get TimeOutSecond() As Double
Property Let TimeOutSecond(TimeSec As Double)

8. BrowserEvents ― ブラウザの"魂"を記録する「器」

非同期イベントを聴くか、聴かざるかを支配するプロパティです。

Property Get BrowserEvents() As Scripting.Dictionary
Property Set BrowserEvents(ObjDic As Scripting.Dictionary)
引数型説明
ObjDicDictionary新しい Dictionary をセットすると記録開始、Nothing で停止します。

9. SetFilterEvents ― "必要な声"だけを聞き届ける、叡智の耳

非同期イベントのうち、特定のメソッド名のみを JSON パース・蓄積させる設定です。大量の Network イベントが発生する際の負荷を劇的に軽減します。

Property Let SetFilterEvents( _
    Optional DelMode As Boolean = False, _
    EventName As String _
)
引数型説明
DelModeBoolean【任意】 True でフィルター削除、False で追加。
EventNameString【必須】 対象のイベントメソッド名。空欄で DelMode:=True なら全削除。
💡

フィルター数が 0 の場合は、すべてのイベントをキャプチャします。必要なイベントが分かっている場合は、これらを明示的に登録することで、スクレイピングのパフォーマンスを最大限に引き出すことができます。
