メソッド リファレンス：CDPContext

CDPContext.cls が公開する Public メソッド・Propertyの完全リファレンスです。
1タブ（Target）単位のナビゲーション、JavaScript 実行、要素検索、イベントキャプチャを担います。

💡
BiDiCDPJson の読み方

ExecuteCDP の戻り値は BiDiCDPJson です。成功時は CDP の result ノードが返ります。エラー時は LastCDPJsonError を参照してください。

🚀 ライフサイクル

StartAndConnectTab Sub

ブラウザ起動とタブ接続を一括で行います（最も一般的なエントリポイント）。

引数名型省略説明
NameString✔ ("chrome")ブラウザ種別
appUrlString✔起動時URL
userProfileString✔プロファイル名
addArgsString✔追加起動引数
KioskModeedgeKioskType✔キオスクモード

reattach / closeTab

reattach(userProfile, reuseSession) で再接続（Boolean）。closeTab でタブを閉じます。

🌐 ナビゲーション・待機

navigate / wait

Public Sub navigate(strURL As String, Optional till As ReadyState = isComplete)
Public Sub wait(Optional till As ReadyState = isComplete, Optional dbgState As Boolean = False)

ReadyState: isLoading, isInteractive, isComplete

📜 JavaScript

jsEval Function

ページ上で JavaScript を実行します。objectId, contextId, IFEXCEPTION 等のオプション引数をサポートします。

LastJavaScriptException (Property Get) で直前の JS 例外情報を取得できます。

jsAddLib / jsAddScript

jsAddLib(strURL) で外部ライブラリを注入。jsAddScript(strLocalScriptPath) でローカルスクリプトを注入します。

⚡ CDP コマンド

ExecuteCDP / ExecuteCDPAsync

Public Function ExecuteCDP(methodName As String, Optional params As Dictionary, Optional StopCDPError As Boolean = True) As BiDiCDPJson
Public Function ExecuteCDPAsync(methodName As String, Optional params As Dictionary, Optional StopPipeError As Boolean = True) As Long

タブスコープの CDP コマンド実行。CDPBrowser と同様の Property: LastCDPJsonError, TakeResultCDP, SetLimitCDPResult, TimeOutSecond

📡 イベントキャプチャ

BrowserEvents Get / Set → Dictionary

非同期 CDP イベントの蓄積を制御します。

渡す値動作
New Dictionaryイベントキャプチャを新規開始
既存の BrowserEvents 値セーブデータから再開
Nothingイベントキャプチャを停止

受信処理は InheritanceCDPBrowser.TakeEvents で行います。

SetFilterEvents Property Let

Property Let SetFilterEvents(Optional DelMode As Boolean = False, EventName As String)

特定イベントのみ JSON パース・蓄積するフィルター。詳細は CDPの高度な制御 を参照。
