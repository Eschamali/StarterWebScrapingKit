メソッド リファレンス：CDPContext

CDPContext.cls が公開する Public メソッド・Propertyの完全リファレンスです。
1タブ（Target）単位のナビゲーション、JavaScript 実行、要素検索、イベントキャプチャを担います。

💡
BiDiCDPJson の読み方

ExecuteCDP 成功時は result ノード。エラー時は LastCDPJsonError を参照。

returnByValueBoolean✔—True：value 受取 / False：objectId 返却

serializationOptionsDictionary✔—返却オブジェクトの細かい調整
generatePreviewBoolean✔—objectId 内容のプレビュー（開発時）
RunAsyncCDPBoolean✔—True：非同期 CDP（コマンド ID 返却）
StopExceptionBoolean✔—True：JS 例外で Err.Raise
StopPipeErrorBoolean✔TrueTrue：パイプエラーで停止

戻り値：Variant。CDP Runtime.evaluate / callFunctionOn ラッパー
