メソッド リファレンス：CDPContext

CDPContext.cls が公開する Public メソッド・Propertyの完全リファレンスです。
1タブ（Target）単位のナビゲーション、JavaScript 実行、要素検索、イベントキャプチャを担います。
各項目をクリックすると、シグネチャ・引数・使い方が展開されます。

💡
BiDiCDPJson の読み方

ExecuteCDP の戻り値は BiDiCDPJson です。成功時は CDP の result ノードが返ります。エラー時は LastCDPJsonError を参照してください。

⚡ CDP コマンド

ExecuteCDP Function → BiDiCDPJsonタブスコープの CDP コマンドを同期送信する 
Public Function ExecuteCDP(methodName As String, Optional params As Scripting.Dictionary, Optional StopCDPError As Boolean = True) As BiDiCDPJson
引数型説明
methodNameStringCDP メソッド名
paramsDictionaryパラメータ Dictionary
StopCDPErrorBoolean失敗時 Err.Raise（デフォルト True）

成功時は CDP result ノード。StopCDPError:=False で失敗時は Nothing → LastCDPJsonError を参照。

ExecuteCDPAsync Function → Longタブスコープの CDP コマンドを非同期送信し、コマンドIDを返す 
Public Function ExecuteCDPAsync(methodName As String, Optional params As Scripting.Dictionary, Optional StopPipeError As Boolean = True) As Long

戻り値のコマンドIDを TakeResultCDP に渡して結果を取得します。事前に InheritanceCDPBrowser.TakeEvents が必要です。

LastCDPJsonError Property Get → Dictionary直前の同期 ExecuteCDP 失敗時のエラー情報 
Property Get LastCDPJsonError() As Dictionary

キー例: "code", "message"。

TakeResultCDP Property Get → String非同期コマンドIDに対応する結果 JSON を取得する 
Property Get TakeResultCDP(commandID As Long) As String

取り出し後はバッファから削除されます。未着の場合は空文字列です。

SetLimitCDPResult Property Let非同期結果バッファの最大保持件数を設定する 
Property Let SetLimitCDPResult(Number As Long)

デフォルトは 10。

TimeOutSecond Property Get/Let → Double同期 CDP コマンドのタイムアウト秒数 
Property Get TimeOutSecond() As Double
Property Let TimeOutSecond(TimeSec As Double)

デフォルトは 30 秒前後。
