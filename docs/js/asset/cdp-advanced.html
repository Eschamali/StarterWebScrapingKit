ExecuteCDP / ExecuteCDPAsync メソッドの取り扱いについて

これらはChrome DevTools Protocol (CDP) のコマンドを直接指定して実行するための低レベル操作用メソッドです。
もしあなたがブラウザのより深く根源的な力を意のままに操りたいと願うなら、この万能の魔法詠唱スティックが力になります。

⚠️
【最重要】使いこなすための"唯一"の掟

何かを要求する前に、まず"挨拶"をせよ。

CDPの Page, Network, DOM などの強力な神々（ドメイン）は、あなたが話しかけるまで眠っています。
挨拶（.enable）なしにいきなり奥義を要求しても、完全なる「沈黙」あるのみです。

【鉄の掟】

〇〇 ドメインのコマンドを使いたいなら、必ず事前に一度だけ ExecuteCDP "〇〇.enable" と唱えなさい。
これは神官の目を開かせるための儀式です。

' 【正しい、儀式の例】
' まず、"挨拶"をする
Demo_NetworkEvent.ExecuteCDP "Page.enable"
Demo_NetworkEvent.ExecuteCDP "Network.enable"

' そして、"要求"する
Demo_NetworkEvent.ExecuteCDP "Page.addScriptToEvaluateOnNewDocument", ...
Demo_NetworkEvent.ExecuteCDP "Network.getCookies", ...

🔥 推奨プラクティス：不要なドメインの disable

特定のドメインを enable した後は、不要になった時点で 対応する disable を呼び出すことを強く推奨します。

理由: enable コマメントを実行するとブラウザはイベントの生成を開始します。VBA側で受け取らなくても、バックグラウンドでの受信・破棄によるオーバーヘッドが発生し続けます。
用が済んだら「もうよい、休んでおれ」と慈悲を与えることで、不要なノイズから解放されたクリーンなライフサイクル管理を実現してください。

🚀
パフォーマンス最適化：イベントフィルタリング

Network ドメインなどは大量の非同期イベントを発生させます。すべてのイベントを律儀に受信・解析していると、VBA側の処理がボトルネックになることがあります。

SetFilterEvents プロパティ（CDPContext に実装）を使用することで、「特定のイベントだけをJSONパース＆蓄積する」という、知的な省エネ運転が可能になります。詳細は CDPContext リファレンス を参照。

SetFilterEvents の使い方

このプロパティにイベント名をセットすることで、フィルタリングリストに追加されます。リストが1つ以上存在する場合、そのリストにあるイベントのみが記録対象となります（CDPContext に実装されています）。

' 収集したいイベントのみを登録する（複数追加可能）
Demo_NetworkEvent.SetFilterEvents = "Network.requestWillBeSent"
Demo_NetworkEvent.SetFilterEvents = "Network.loadingFinished"

' (オプション) 特定の環境だけフィルターから削除したい場合
Demo_NetworkEvent.SetFilterEvents(DelMode:=True) = "Network.loadingFinished"

' 全削除（フィルター解除 ＝ 全キャプチャに戻る）
Demo_NetworkEvent.SetFilterEvents(DelMode:=True) = ""

メリット: 不要なイベントのJSONパース処理がスキップされるため、高負荷なサイトのスクレイピングや、大量の通信が発生する状況で劇的なパフォーマンス向上が期待できます。
