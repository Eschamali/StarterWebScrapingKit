メソッド リファレンス：WebDriverBiDiMode

WebDriverBiDiMode.cls が公開する Public メソッド・Propertyの完全リファレンスです。
ブラウザ単位（--user-data-dir 相当）の BiDi 制御はこのクラスが担います。タブ単位の操作は WebDriverBiDiContext を参照してください。
各項目をクリックすると、シグネチャ・引数・使い方が展開されます。

💡
BiDiCDPJson の読み方

ExecuteBiDi の戻り値は BiDiCDPJson です（旧 Dictionary ではありません）。

Dim resultBiDi As BiDiCDPJson
Set resultBiDi = mode.ExecuteBiDi("browsingContext.getTree")
If Not resultBiDi Is Nothing Then
    Debug.Print resultBiDi.StringKey("context")          ' キー文字列
    Set child = resultBiDi.NodeKey("result")             ' 子ノード
End If
' エラー時（StopBiDiError:=False）: Nothing → .LastBiDiJsonError で詳細確認

⚙️ WebDriverBiDiCore（低レベル）

WebDriverBiDiCore.cls はパイプ通信・マッパー管理を担う内部層です。通常は WebDriverBiDiMode 経由で利用します。直接触るのは主に mapperTab.js 更新 と WithEvents です。
