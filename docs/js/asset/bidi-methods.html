メソッド リファレンス：WebDriverBiDiMode

WebDriverBiDiMode.cls が公開する Public メソッド・Propertyの完全リファレンスです。
ブラウザ単位（--user-data-dir 相当）の BiDi 制御はこのクラスが担います。タブ単位の操作は WebDriverBiDiContext を参照してください。

💡
BiDiCDPJson の読み方

ExecuteBiDi の戻り値は BiDiCDPJson です（旧 Dictionary ではありません）。

Dim resultBiDi As BiDiCDPJson
Set resultBiDi = mode.ExecuteBiDi("browsingContext.getTree")
If Not resultBiDi Is Nothing Then
    Debug.Print resultBiDi.StringKey("context")          ' キー文字列
    Set child = resultBiDi.NodeKey("result")             ' 子ノード
End If
' エラー時（StopBiDiError:=False）: Nothing → .LastBiDiJsonError で詳細確認

ブラウザを起動し、BiDiマッパーの注入から session.new によるセッション確立までを一括で行います。

KioskModeedgeKioskType✔キオスクモード種別

reattach Function → Boolean

起動中のデバッグブラウザへ再接続し、BiDiセッションを再確立します。

引数名型省略説明
userProfileString✖再接続するプロファイル名
sessionCapabilitiesRequestDictionary✔再起動時の Capability

戻り値：True = 成功 / False = 失敗

newTab / getTab Function → WebDriverBiDiContext

新規タブの生成、または既存コンテキストの取得。戻り値は WebDriverBiDiContext です。

getTab は Url, maxDepth, setMain, doRetrySecond を指定できます。

ExecuteBiDi Function → BiDiCDPJson

BiDiコマンドを 同期 送信します。ブラウザから結果が返るまで待機します。

Public Function ExecuteBiDi( _
    ByVal methodName As String, _
    Optional params As Dictionary, _
    Optional StopBiDiError As Boolean = True _
) As BiDiCDPJson
引数名型省略デフォルト説明
methodNameString✖—BiDiメソッド名（例: "browsingContext.navigate"）
paramsDictionary✔—コマンドパラメーター
StopBiDiErrorBoolean✔TrueFalse 時は Nothing を返して継続
⚠️ エラー時: StopBiDiError:=False で Nothing が返った場合は .LastBiDiJsonError を参照してください。

ExecuteBiDiAsync Function → Long

BiDiコマンドを 非同期 送信します。戻り値のコマンドIDで後から TakeResultBiDi により結果を取得します。

受信バッファを処理し、BiDiEvents への蓄積・非同期結果の回収を行います。

Public Sub TakeEvents(Optional StopPipeError As Boolean = True, Optional destruction As Boolean = False)

sleep Sub

指定秒数待機（デフォルト 0.5 秒）。

quit Sub

ブラウザを正常終了し、内部リソースを解放します。

📦 Property

BiDiEvents Get / Set → Dictionary

非同期イベントのキャプチャ状態を制御します。

渡す値動作
New Dictionaryイベントキャプチャを新規開始
既存の BiDiEvents 値セーブデータから再開
Nothingイベントキャプチャを停止

sessionSubscribe Set

購読するイベント名の Collection をセットします。内部で session.subscribe / session.unsubscribe を呼び出します。

Dim eventsArray As New Collection
eventsArray.Add "network.responseCompleted"
Set mode.sessionSubscribe = eventsArray

LastBiDiJsonError Get → Dictionary

直前の ExecuteBiDi 失敗時のエラー詳細。キー: "error", "message", "stacktrace"

TakeResultBiDi Get → String

ExecuteBiDiAsync で送信したコマンドIDの結果JSON文字列を取得します。取り出し後はバッファから削除されます。未着の場合は空文字列です。

SetLimitBiDi Let → Long

非同期結果バッファの上限件数（デフォルト 10）。

TimeOutSecond Get / Let → Long

同期コマンドのタイムアウト秒数（デフォルト 30）。

⚙️ WebDriverBiDiCore（低レベル）

WebDriverBiDiCore.cls はパイプ通信・マッパー管理を担う内部層です。通常は WebDriverBiDiMode 経由で利用します。直接触るのは主に mapperTab.js 更新 と WithEvents です。

Sub StartAndListen()
