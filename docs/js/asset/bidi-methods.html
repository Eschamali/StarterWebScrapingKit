メソッド リファレンス：WebDriverBiDiCore

WebDriverBiDiCore.cls が公開する Publicメソッド・Propertyの完全リファレンスです。

🔧 Public メソッド

start Sub

ブラウザを起動し、BiDiマッパーの注入からセッション確立までを一括で行います。
内部では CDPBrowser.start → StartBiDiCDPMapper → session.new の順に処理されます。

引数名型省略デフォルト説明
NameString✔"chrome"使用するブラウザ名。"chrome" または "edge"
appUrlString✔—起動時に遷移するURL。省略時は空ページ
cleanActiveBoolean✔TrueTrue：既存のデバッグブラウザをKillして起動。False：チェックなしで新規起動
userProfileString✔—UserDataDir のプロファイル名
addArgsString✔—追加の起動引数
KioskModeedgeKioskType✔00:通常 / 1:キオスク(サイネージ) / 2:キオスク(パブリック)
sessionCapabilitiesRequestDictionary✔—session.new に渡すCapabilityパラメーター

戻り値：なし (Sub)

reattach Function → Boolean

すでに起動中のデバッグブラウザへ再接続し、BiDiセッションを再確立します。
マッパーが生きているか・URLが適切かを自動判定してリカバリーします。

引数名型省略説明
userProfileString✖再接続するブラウザのプロファイル名
sessionCapabilitiesRequestDictionary✔session.new のCapabilityパラメーター（再起動時のみ使用）

戻り値：True = 再接続成功 / False = 失敗

invokeMethod Function → Dictionary

BiDiコマンドを 同期 送信します。ブラウザから結果が返るまで待機します。

Public Function invokeMethod( _
    ByVal methodName As String, _
    Optional params As Dictionary, _
    Optional StopError As Boolean = True _
) As Dictionary
引数名型省略デフォルト説明
methodNameString✖—BiDiメソッド名（例: "browsingContext.navigate"）
paramsDictionary✔—コマンドパラメーター
StopErrorBoolean✔TrueTrue：失敗時に Err.Raise で停止。False：Nothing を返して処理継続

戻り値：BiDi結果の result オブジェクト (Dictionary)。エラー時は Nothing（StopError=False の場合）

⚠️ エラー時の確認先: StopError:=False で Nothing が返った場合は .LastBiDiJsonError でエラー詳細を確認してください。

invokeMethodAsync Function → Long

BiDiコマンドを 非同期 送信します。結果を待たず即座に次の処理へ進みます。

Public Function invokeMethodAsync( _
    ByVal methodName As String, _
    Optional params As Dictionary _
) As Long
引数名型省略説明
methodNameString✖BiDiメソッド名
paramsDictionary✔コマンドパラメーター

戻り値：コマンドID (Long)。後から ResultBiDiForAsync に渡すことで結果を取得できます。

TakeEvents Sub

受信バッファを空になるまで処理し、BiDiEvents への蓄積・非同期結果の回収を行います。
invokeMethod の内部でも自動呼び出しされますが、イベント待ち受けのポーリングループでも手動使用します。

Public Sub TakeEvents(Optional destruction As Boolean)
引数名型省略デフォルト説明
destructionBoolean✔FalseTrue：中身を解析せず即破棄（高速クリア）。False：IDとイベントを解析・格納

戻り値：なし (Sub)

sleep Sub

指定秒数だけ処理を一時停止します。

引数名型省略デフォルト説明
SecondsDouble✔1待機する秒数（小数可）

quit Sub

ブラウザを正常に終了します。内部リソースもすべて解放されます。

引数・戻り値：なし

📦 Property

BiDiEvents Get / Set → Dictionary

非同期イベントのキャプチャ状態を制御します。渡す値によって動作が変わります。

Property Get BiDiEvents() As Dictionary
Property Set BiDiEvents(ObjDic As Dictionary)
渡す値動作
New Dictionary（空）イベントキャプチャを新規開始。内部で構造を自動初期化します
既存の BiDiEvents 値セーブデータから再開。追記モードになります
Nothingイベントキャプチャを停止・破棄します

Getの戻り値：蓄積済みの Dictionary。キー構造：TotalEvents (Long) + EventMethods (Dictionary of Collections)

LastBiDiJsonError Get → Dictionary

直前の invokeMethod が失敗したときのエラー詳細を返します。

主なキー説明
"error"エラー種別文字列（例: "unknown command"）
"message"エラーメッセージ
"stacktrace"スタックトレース（存在する場合のみ）
💡 注意: 成功しても値はリセットされません（Err.LastDllError と同じ思想）。必ず invokeMethod の戻り値が Nothing のときのみ参照してください。

ResultBiDiForAsync Get → Dictionary

invokeMethodAsync で送信したコマンドの結果を、IDを指定して後から取り出します。

Property Get ResultBiDiForAsync( _
    CommandID As Long, _
    ErrorExist As Boolean _
) As Dictionary
引数名型説明
CommandIDLonginvokeMethodAsync が返した整理券番号
ErrorExistBoolean（参照渡し）True = IDが見つからない or エラー。実質的な第2戻り値

戻り値：成功時は result オブジェクト、エラー時はエラー情報の Dictionary。取り出し後はバッファから自動削除されます。

ResultAccumulatedLimitBiDiForAsync Get / Let → Long

invokeMethodAsync の結果バッファ上限件数を設定します。

項目値
デフォルト10
上限超過時古いエントリから自動削除

TimeOutSecond Get / Let → Long

invokeMethod がブラウザからの返答を待つタイムアウト時間（秒）を設定します。

項目値
デフォルト30（秒）
超過時エラーログ出力 → 強制終了

⚡ Event

detectionBiDiEvent

非同期イベントを受信したとき、VBAモジュール側でリアルタイムに反応できるイベントです。
WithEvents 変数として宣言することで使用できます。

Public Event detectionBiDiEvent(methodName As String, EventRawJson As String)
引数名型説明
methodNameString受信したイベント名（例: "network.responseCompleted"）
EventRawJsonStringブラウザから届いたイベントのRaw JSON文字列
使用例（WithEvents による宣言） 
' モジュールレベルで宣言
Private WithEvents m_Bidi As WebDriverBiDiCore

Sub StartAndListen()
    Set m_Bidi = 設定シートからのBiDi起動
End Sub

' イベントハンドラー（自動補完で出てきます）
Private Sub m_Bidi_detectionBiDiEvent(methodName As String, EventRawJson As String)
    If methodName = "network.responseCompleted" Then
        Debug.Print "通信完了: " & EventRawJson
    End If
End Sub
