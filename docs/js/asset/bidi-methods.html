メソッド リファレンス：WebDriverBiDiMode

WebDriverBiDiMode.cls の完全リファレンス。ブラウザ単位の BiDi 制御。タブ操作は WebDriverBiDiContext。

💡
BiDiCDPJson の読み方

ExecuteBiDi の戻り値は BiDiCDPJson です。

Dim resultBiDi As BiDiCDPJson
Set resultBiDi = mode.ExecuteBiDi("browsingContext.getTree")
If Not resultBiDi Is Nothing Then Debug.Print resultBiDi.StringKey("context")
